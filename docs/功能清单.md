# 鸭子乐园 — 功能清单

依据 `docs/需求.md` 整理。仅微信小程序，会员在小程序内使用微信支付。虚拟商品，无物流。金额单位为人民币元，保留两位小数。

编号规则：

- 终端用前缀区分：`MP` 微信小程序，`AD` 管理平台。
- 主功能模块对应菜单，如 `MP-01`。
- 子功能模块如 `MP-01-03`。
- 功能点如 `MP-01-03-01`。每个功能点单独一行。

状态：

- **需求明确**：原文或已确认的产品要求。
- **闭环配套**：原文没单列，但没有它，已写明的能力无法落地。

---

## 一、微信小程序

未登录可浏览款式。下单、支付、查看鸭子和订单、更换皮肤、申请退款，必须已登录且已绑定手机号。
